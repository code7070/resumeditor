# ATS Rule-Set Documentation

## About ATS

**Applicant Tracking System (ATS)** is software used by companies to automatically screen, manage, and organize resumes/CVs. This system scans application documents before they are reviewed by human recruiters.

### Primary Functions of ATS

- Parsing information from resumes into a database
- Filtering candidates based on keywords and criteria
- Ranking candidates based on relevance
- Managing end-to-end recruitment processes

### Important Statistics

- 75-90% of resumes are rejected by ATS before being seen by humans
- 90%+ Fortune 500 companies use ATS
- 70%+ resumes fail ATS screening due to poor formatting

## ATS Rule-Set: Format & Structure

### 1. File Format

**✅ Recommended:**

- `.docx` (Microsoft Word) - most compatible
- `.pdf` - safe if created from Word/Google Docs, not scanned

**❌ Avoid:**

- `.jpg`, `.png`, or image formats
- Scanned/photographed PDFs
- `.pages` (Mac format)
- Uncommon formats

### 2. Document Structure

**Simple Layout:**

- Use single-column layout
- Avoid tables for main information
- Don't use text boxes
- Minimal headers and footers (avoid important info here)

**Clear Headings:**

```
WORK EXPERIENCE / PROFESSIONAL EXPERIENCE
EDUCATION
SKILLS
CERTIFICATIONS
```

### 3. Typography

**Safe Fonts:**

- Arial
- Calibri
- Times New Roman
- Georgia
- Helvetica
- Garamond

**Font Sizes:**

- Body text: 10-12pt
- Name: 14-16pt
- Headings: 12-14pt

**Formatting:**

- ✅ Bold for emphasis
- ✅ Italic for light emphasis
- ❌ Avoid underline (can be mistaken for links)
- ❌ Avoid colored text (use black)

## ATS Rule-Set: Content

### 1. Required Sections (In Order)

1. **Header/Contact Information**

   - Full name
   - Phone number
   - Professional email
   - Location (city/country)
   - LinkedIn URL (optional)
   - Portfolio/website (if relevant)

2. **Professional Summary** (optional but recommended)

   - 2-4 sentences
   - Highlight main experience and expertise
   - Include keywords from job description

3. **Work Experience**

   - Reverse chronological order (most recent first)
   - Format: Job Title | Company Name | Location | Dates
   - Bullet points for achievements (not just responsibilities)
   - Use action verbs and quantify results

4. **Education**

   - Degree | Major
   - Institution name
   - Graduation year or period
   - GPA (if > 3.5 or requested)

5. **Skills**

   - Technical skills
   - Soft skills
   - Languages
   - Tools & software

6. **Additional Sections** (if relevant)
   - Certifications
   - Projects
   - Publications
   - Awards
   - Organizations/Volunteer work

### 2. Keywords

**Keyword Strategy:**

- Read job description carefully
- Identify recurring keywords
- Insert keywords naturally throughout resume
- Use keyword variations (e.g., "project management" and "managed projects")

**Example Keywords by Industry:**

**Tech/IT:**

- Programming languages (Python, Java, JavaScript)
- Frameworks (React, Django, Spring Boot)
- Tools (Git, Docker, Kubernetes)
- Methodologies (Agile, Scrum, DevOps)

**Marketing:**

- Digital marketing, SEO, SEM, PPC
- Google Analytics, Google Ads
- Content marketing, social media marketing
- Marketing automation, CRM

**Finance:**

- Financial analysis, budgeting, forecasting
- Excel, SAP, QuickBooks
- Financial modeling, variance analysis
- GAAP, IFRS compliance

### 3. Date Format

**✅ Consistent and Clear:**

- January 2022 - March 2024
- Jan 2022 - Mar 2024
- 01/2022 - 03/2024

**❌ Avoid:**

- Ambiguous formats: 01/02/2022 (is it January or February?)

### 4. Writing Work Experience

**STAR Formula:**

- **S**ituation: Context
- **T**ask: Challenge faced
- **A**ction: Action taken
- **R**esult: Measurable results

**Examples:**
❌ "Responsible for managing team"
✅ "Led team of 5 developers to build mobile application, increasing user engagement by 40% in 6 months"

**Strong Action Verbs:**

- Achieved, Implemented, Developed, Managed
- Increased, Reduced, Improved, Optimized
- Led, Coordinated, Facilitated, Collaborated
- Designed, Created, Launched, Established

## ATS Rule-Set: What to Avoid

### 1. Complex Visual Elements

❌ **Avoid:**

- Graphics and charts
- Infographics
- Icons and symbols
- Progress bars for skills
- Images and photos (unless requested)
- Watermarks
- Background images

### 2. Formats that Confuse ATS

❌ **Avoid:**

- Tables for work experience
- Two-column layout
- Text boxes
- Headers and footers for important info
- Non-standard sections (e.g., "My Journey" instead of "Experience")

### 3. Common Mistakes

❌ **Avoid:**

- Typos and grammatical errors
- Abbreviations without explanation
- Irrelevant information
- Lies or exaggeration
- First-person pronouns (I, me, my)
- Full address (city is sufficient)
- References (write "available upon request" or omit)

## ATS Rule-Set: Best Practices

### 1. Keyword Optimization

**Steps:**

1. Copy job description
2. Highlight frequently appearing keywords
3. Insert these keywords in:
   - Professional summary
   - Skills section
   - Work experience (if relevant)
4. Use exact match for job titles and technical terms

### 2. Customization for Each Application

**Don't Send Generic Resume:**

- Tailor professional summary to the position
- Prioritize most relevant experience
- Match keywords from job description
- Adjust skills section to highlight what's requested

### 3. Quantify Achievements

**Use Numbers:**

- Percentage increase
- Dollar amounts (revenue, budget, savings)
- Number of people/teams managed
- Timeframes
- Scope of work

**Examples:**

- "Increased sales by 35%"
- "Managed $500K budget"
- "Led team of 10 people"
- "Completed project 2 weeks ahead of schedule"

### 4. Testing Your Resume

**Tools for ATS-Compatibility Testing:**

- Jobscan.co
- Resume Worded
- TopResume
- SkillSyncer

**Manual Test:**

- Copy-paste resume into Notepad/simple text editor
- If formatting is messy, ATS will struggle too
- Ensure all important info remains readable

## Regional Tips: Global Considerations

### International vs. US Resumes

**In many countries, it's common to include:**

- Date of birth
- Marital status
- Photo

**Recommendations:**

- For multinational companies/startups: follow Western format (no photo, DOB, marital status)
- For local/traditional companies: adapt to their expectations
- Read job posting carefully for clues

### Language

**Local Language:**

- Use if job posting is in local language
- Still include technical keywords in English if commonly used

**English:**

- Use if job posting is in English
- For positions at multinational companies
- For positions requiring English proficiency

## FAQ

**Q: Do all companies use ATS?**
A: Not all, but the majority of large and medium-sized companies use ATS. Small startups might still review manually.

**Q: What's the ideal resume length?**
A: 1 page for fresh graduates or < 5 years experience. 2 pages for more senior professionals. Maximum 2 pages.

**Q: Can I use creative templates?**
A: For creative positions (design, creative marketing) yes, but ensure the basic structure is ATS-friendly. For technical/corporate positions, use simple format.

**Q: What if my experience doesn't match exactly?**
A: Focus on transferable skills. Show how your experience is relevant to the applied position through achievements and transferable skills.

**Q: Should I include all work experience?**
A: No. Prioritize what's relevant to the applied position. Experience > 10-15 years old can be summarized or omitted if not relevant.
